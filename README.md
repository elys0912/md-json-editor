# md-json-editor

ブラウザだけで動く Markdown・JSON のビューワー兼エディタです。ファイルを開いて読み、必要なら少し直して、ダウンロードで保存します。

https://elys0912.github.io/md-json-editor/

## できること

| 形式 | 拡張子 | 表示 |
|---|---|---|
| Markdown | .md .markdown .txt | プレビュー（既定）／編集＋プレビュー／編集 |
| JSON | .json | ツリー（既定）／テキスト |
| JSON5 | .json5 | ツリー（既定）／テキスト |
| JSON Lines・NDJSON | .jsonl .ndjson | 行一覧（既定）／全行のツリー／テキスト |
| GeoJSON | .geojson（.json で中身が GeoJSON のときも） | 図形（既定）／ツリー／テキスト |

- Markdown：表・取り消し線・タスクリスト、コードの色付け、目次、編集とプレビューのスクロールの連動、.md と .html（スタイル込みの 1 ファイル）での書き出し
- JSON：誤りの行・列の表示と、その位置への移動。ツリーの全開・全閉・検索・パスの写し（例 `$.items[2].name`）。整形（インデント 2・4・タブ）と圧縮。整形と圧縮では数値や文字列の書き方を変えません
- JSON Lines：誤りのある行を示し、ほかの行は表示を続けます。JSON の配列との相互の変換
- GeoJSON：RFC 7946 の構造を検証し、誤りと注意をパスつきで示します。背景地図なしで図形を描き、拡大・移動と、クリックした図形の properties の表示ができます
- 共通：ファイルの選択・ドラッグ＆ドロップ・貼り付けで開く、文書の一覧と切替、ライト・ダーク・OS に合わせるのテーマ

ショートカット：Ctrl+S ダウンロード、Ctrl+O ファイルを開く、Ctrl+E 表示の切替、Ctrl+F 検索

## オフラインで使えます

一度開くと、通信なしでも全機能が動きます（PWA）。ホーム画面やデスクトップにインストールもできます。新しい版が出たときは画面下に知らせが出て、［更新］を押すと切り替わります。

## 文書の保存について

- 開いた文書と編集は、この端末のブラウザの中（IndexedDB）にだけ自動で保存されます。外部へは送りません。解析や広告、利用状況の計測も入れていません
- 元のファイルは書き換えません。ファイルとして残すときはダウンロードしてください
- ブラウザが保存した内容を消す場合があります（空き容量が少ないときなど）。大事な文書はダウンロードで控えを取ってください
- プライベートブラウズなど保存できない環境では、文書をメモリだけで持って動きます。閉じると内容は消えます

## 通信が起きる場合

外部の画像（`![](https://…)`）を含む Markdown を開くと、プレビューで表示するためにその画像の配信元へ通信が起きます。

## 既知の制限

- ツリーの表示では、2^53 を超える整数の精度が落ちます（テキストと整形の結果は元のままです）
- JSON5 の整形・圧縮では、コメントと数値の書き方が失われます（実行の前に確認を出します）
- 経度 180 度をまたぐ GeoJSON は、補正せずに描きます
- 書き出した HTML では、ページ内リンク（`#…`）で見出しへ移りません
- PDF の書き出しはありません。ブラウザの印刷から PDF にしてください（印刷では本文だけが出ます）
- UTF-8 以外の文字コードのファイルは開けません。50 MB を超えるファイルも開けません

## 開発

Node.js 24 で動かします。

```sh
npm ci
npm run dev        # 開発用のサーバー
npm test           # テスト（vitest ＋ jsdom）
npm run lint
npm run typecheck
npm run build      # dist/ に出力
```

main への push で GitHub Pages に配置します（.github/workflows/deploy.yml）。
